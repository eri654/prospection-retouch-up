# Prospection terrain Retouch'Up

Ce dépôt héberge les tableaux de prospection consultables sans compte Claude.

## Tableau disponible

- [Paris · EquipHotel 2026](paris_equiphotel_2026.html) : 21 hôtels, 47 contacts, cases à cocher par hôtel et par contact.

## Fonctionnement

- Les coches, priorités et notes sont enregistrées uniquement dans le navigateur utilisé. Elles ne sont pas synchronisées entre utilisateurs ou appareils.
- Les liens HubSpot ouvrent les fiches dans le portail Retouch'Up pour les personnes ayant accès à ce portail. Quarante contacts ont un identifiant vérifié. Les sept autres restent sans lien vérifié.
- Les numéros mobiles et les clés API ne figurent pas dans cette version publique. Les numéros standards des hôtels restent affichés.
- Le statut Lemlist en direct n'est pas disponible sur cette page. Le bouton Infos permet d'ouvrir Lemlist dans un nouvel onglet.

Pour ajouter un tableau, déposer son fichier HTML dans ce dépôt et ajouter un lien dans `index.html`.
